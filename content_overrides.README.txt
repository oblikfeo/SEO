Этот файл — рабочая база SEO-контента на ПРОДАКШЕНЕ.

  • SEO-специалист правит страницы через https://nadezhda.info/admin/
  • Каждое «Сохранить и опубликовать» перезаписывает ЭТОТ файл на сервере
  • build_pages.py собирает public/ с учётом overrides

В GIT (GitHub oblikfeo/SEO) здесь должен быть только пустой шаблон:

  {}

НЕ коммитить в git тексты страниц из продакшена.
НЕ деплоить git reset --hard без scripts/safe_git_update.sh — иначе
недели работы SEO будут безвозвратно стёрты (инцидент 2026).

Правильный деплой на VPS:
  cd /var/www/seo && bash scripts/safe_git_update.sh
