# nadezhda.info — инструкция для Claude Code

Статический SEO-сайт VPN-сервиса «Надежда». Python-сборка без npm и зависимостей: контент и шаблоны из этого репозитория превращаются в HTML.

## Главное

**Коммит в ветку `main` = выкладка на сайт.** Сервер проверяет репозиторий раз в минуту, сам собирает сайт и переключает его. Ручной админки, SSH и других шагов нет.

После пуша проверь результат: https://nadezhda.info/deploy-status.txt

- `result: OK` и твой коммит — сайт обновлён.
- `result: FAILED` — сайт не изменился, старая версия работает. Причина написана там же. Исправь и закоммить снова.

Репозиторий **публичный**. Не коммить пароли, токены и ключи.

## Где что лежит

| Что | Где |
|---|---|
| Контент страницы | `content/<путь>/page.json` (главная — `content/page.json`) |
| Дерево URL, меню разделов, подписи | `scripts/site_data.py` |
| Вёрстка: шапка, подвал, блоки, HTML страницы | `scripts/build_pages.py` (`page_shell`, `header_html`, `footer_html`, `render_*`) |
| Стили | `assets/css/` |
| Картинки | `assets/img/` → на сайте `/assets/img/имя.png` |
| Настройки: ссылки, Метрика, UTM | `site_config.json` |
| Автосборка на сервере | `deploy/` |

Каталог `public/` — результат сборки, в git его нет. Не правь его руками.

## Формат page.json

Страница `/devices/mobile/android/` → файл `content/devices/mobile/android/page.json`:

```json
{
  "title": "Тег title",
  "description": "Мета-описание",
  "h1": "Заголовок страницы",
  "schemas": ["software_app"],
  "sections": [
    { "type": "snippet", "text": "Короткий абзац под заголовком" },
    { "type": "prose", "html": "<h2>Подзаголовок</h2><p>Текст</p>" }
  ]
}
```

Обязательны `title`, `description`, `h1`, `sections`. Необязательны:

- `h1_html` — заголовок с HTML-разметкой, заменяет `h1` в вёрстке.
- `schemas` — разметка JSON-LD: `organization`, `software_app`.

Блоки выводятся в том порядке, в каком стоят в `sections`:

| type | Поля | Что это |
|---|---|---|
| `snippet` | `text` | короткий абзац-сниппет, до 300 знаков |
| `prose` | `html` | основной текст: h2, h3, p, ul, ссылки |
| `table` | `headers`, `rows` | таблица; не вставляй `<table>` в `prose` |
| `faq` | `items: [{q, a}]` | вопросы и ответы с разметкой FAQPage |
| `howto` | `items: [{key, label}]` | шаги с разметкой HowTo; `key`: `registration`, `apk`, `import` подставляют готовые шаги со ссылками, другой `key` выводит `label` |
| `trial` | — | блок «8 часов бесплатно» |
| `cards` | `items: [{title, desc, href, tag}]`, `columns` | карточки со ссылками; `columns: 3` — сетка в три колонки |
| `child_cards` | — | карточки дочерних страниц, строятся из дерева URL сами (разделы и хабы) |
| `related` | `title`, `items: [{label, href}]` | блок ссылок |

Блок навигации по разделу внизу страницы, хлебные крошки и шапка добавляются сами.

## Новая страница

1. В `scripts/site_data.py` добавь slug в `LEAVES` (страница хаба) или `SUBLEAVES` (вложенная) и подпись в `LABELS`.
2. Создай `content/<путь>/page.json`.
3. Собери и проверь, закоммить.

Страница сама появится в карточках хаба, блоках навигации и `sitemap.xml`. Сборка остановится с ошибкой, если у страницы нет файла или у файла нет страницы в дереве.

## Проверка перед коммитом

```bash
python scripts/build_pages.py     # собирает public/
python scripts/check_seo.py       # title, description, один h1 на странице и т.д.
python -m http.server 8080 --directory public
```

На Windows перед запуском: `set PYTHONUTF8=1`.

Сервер выполняет те же две команды. Если `check_seo.py` падает, сайт не обновится.

## Откат

`git revert <коммит>` и пуш: сайт вернётся через минуту.

## Важно

- Изменения в `deploy/` на сервер сами не попадают: скрипт автосборки установлен отдельно администратором. Сообщи ему, если нужно их применить.
- Смена URL ломает позиции в поиске. Меняй адреса существующих страниц только осознанно.
- Домен nadezhda.space и сервис VPN в этом репозитории не правятся: ссылки на них берутся из `site_config.json`.
